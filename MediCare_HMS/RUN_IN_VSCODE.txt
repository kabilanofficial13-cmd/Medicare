HOW TO RUN IN VISUAL STUDIO CODE (3 steps)

1) Unzip, then in VS Code: File > Open Folder > select the MediCare_HMS folder.
   (Install the "Python" extension if VS Code asks.)

2) Open the Terminal (Ctrl + `) and run once:
       python -m pip install -r requirements.txt

3) Press F5  (or click Run > Start Debugging > "Run MediCare HMS").
   The browser opens at http://127.0.0.1:5000

   Or just double-click run.bat instead.
